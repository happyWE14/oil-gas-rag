# Frontend

Vue 3, Vite, Element Plus, and ECharts UI for the literature RAG system.

```bash
cp .env.example .env
npm install
npm run dev
```

`VITE_API_ORIGIN` may be left empty when the frontend and backend share an origin or when the Vite development proxy is used.

See the repository-level [English README](../README.md) or [中文 README](../README.zh-CN.md) for the full setup and capability boundaries.
